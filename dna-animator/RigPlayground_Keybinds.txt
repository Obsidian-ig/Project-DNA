CTRL KEYBINDS:
------------------------------------------------------
CTRL + S = Save Rig
CTRL + N = Create New Group/Element/Point/Control Point depending on what the selected node is.
CTRL + Z = Undo Last Change to Rig
CTRL + Y = Redo Last Change to Rig
CTRL + F = Open Find Node prompt to search for a node in the tree by name



ALT KEYBINDS:
------------------------------------------------------
ALT + E = Expand/Collapse everything in the rig tree



CTRL + SHIFT KEYBINDS:
------------------------------------------------------
CTRL + SHIFT + S = Save Rig As
CTRL + SHIFT + M = Import New Rig
CTRL + SHIFT + C = Close Rig
CTRL + SHIFT + N = New Rig
CTRL + SHIFT + R = Create Rig Restore Point
CTRL + SHIFT + L = Load Rig Restore Point
CTRL + SHIFT + O = Open Rig In File Explorer
CTRL + SHIFT + E = Export Rig Preview As Png
CTRL + SHIFT + T = Toggle Rig Tree
CTRL + SHIFT + P = Toggle Properties Explorer
CTRL + SHIFT + V = Toggle Visual Editing Mode On/Off
